# VIDEO.md — creative decisions for the entry video

## The subject

An AI coding agent building a tiny browser game from one prompt, while the
viewer watches. The video must show the prompt, the agent working, and the
finished game in one short clip, and end on the game running with the call
to come build on make.fun.

## The creative

Vertical 1080x1920, about 40 seconds, four beats:

1. **The prompt (0-4s).** A single line types itself onto a dark screen:
   "Build me a tiny browser game." The hook is the whole premise in one
   sentence — a viewer who has ever wished something into existence stays
   to see whether it works.
2. **The agent working (4-16s).** A terminal window: files appearing, code
   landing line by line, the self-test going green. Real footage of the
   actual build session, not a mockup — the proof is the point.
3. **The finished game (16-34s).** Mochi Drop playing itself in autoplay:
   pink and gold mochi raining down, the plate catching them, the score
   climbing, a combo flashing. The game is the payoff, so it gets the
   longest beat and fills the frame.
4. **The call (34-38s) + end card.** "Your turn — come build on make.fun"
   over the game still running, then make.fun's referral end card with my
   referral code, used as issued from the press pack.

## Why this game

The bounty board's top ten is crowded with neon dodgers — five of the top
ten are the same dark-neon dodge game with a different name. A pastel catch
game about mochi reads instantly in a feed full of neon, and its mechanic
(catch the good ones, dodge the burnt ones) needs no explanation. The game
is genuinely built in this session, in one file, with an autoplay mode so
the footage shows it playing itself and a self-test so the build is
provably real.
